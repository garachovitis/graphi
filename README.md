# Grafi

Επεξεργαστής κειμένου για **macOS, Windows, Linux, iOS, Android και web (PWA)**.
Ανοίγει και αποθηκεύει **DOCX** και **ODT**, εξάγει **PDF**, εκτυπώνει, και η σελιδοποίηση στην οθόνη
είναι ίδια με αυτή του χαρτιού και του PDF.

```bash
npm install
npm run dev          # Electron με hot reload
npm run dev:web      # μόνο web (http://localhost:5199)
npm run typecheck
npm run build        # production build στο dist/
npm run dist:mac     # .dmg / .zip   (arm64 + x64)
npm run dist:win     # NSIS installer + portable
npm run dist:linux   # AppImage, .deb, .rpm
```

Για νέα έκδοση με `.exe` στο GitHub Releases (αυτόματο build μέσω GitHub Actions) βλ. [RELEASING.md](RELEASING.md).

## Τεχνολογίες

TypeScript · React 19 · TipTap 3 / ProseMirror · Electron 44 · Capacitor 8 · Vite 8 · `docx` · JSZip.

Η διάταξη κειμένου, η εκτύπωση και το PDF γίνονται από τον ίδιο Chromium σε όλα τα desktop λειτουργικά,
οπότε οι γραμμές και οι σελίδες σπάνε παντού στο ίδιο σημείο. Οι γραμματοσειρές Carlito (≅ Calibri) και
Arimo (≅ Arial) είναι ενσωματωμένες και metric-compatible, ώστε το κείμενο να αναδιπλώνεται ίδια και σε
υπολογιστή χωρίς Office.

### Σελιδοποίηση

Το έγγραφο επεξεργάζεται ως μία στήλη με το πλάτος κειμένου της σελίδας. Μετά από κάθε αλλαγή μετριέται η
θέση κάθε γραμμής και τοποθετούνται αόρατα spacers (decorations, όχι περιεχόμενο) ώστε:

- καμία γραμμή να μη διασχίζει το κάτω περιθώριο — οι παράγραφοι σπάνε ανάμεσα σε γραμμές·
- να τηρείται ο έλεγχος ορφανών/χήρων γραμμών·
- οι επικεφαλίδες να μένουν με την επόμενη παράγραφο·
- πίνακες και εικόνες να μετακινούνται ολόκληρα·
- στην εκτύπωση κάθε spacer να γίνεται αλλαγή σελίδας, άρα PDF = οθόνη.

Στο iOS ο print formatter του WebKit σμικρύνει τη σελίδα, γι' αυτό κάθε σελίδα της οθόνης αποτυπώνεται
διανυσματικά (`WKWebView.createPDF`, βλ. `platform.ts → withPageRects` και `AppDelegate.swift`).
Το Android χρησιμοποιεί Chromium, όπως το desktop.

## Λειτουργίες

- **Κεντρική:** πρόχειρο, πινέλο μορφοποίησης, γραμματοσειρά & μέγεθος, έντονα/πλάγια/υπογράμμιση/διακριτή
  διαγραφή, δείκτης/εκθέτης, επισήμανση, χρώμα, λίστες, εσοχές, στοίχιση, διάστιχο, σκίαση, στυλ,
  εύρεση/αντικατάσταση (με/χωρίς τόνους, ολόκληρες λέξεις, regex).
- **Εισαγωγή:** αλλαγή σελίδας, πίνακας, εικόνες (αρχείο, URL, επικόλληση, σύρσιμο), σχήματα, υπογραφή,
  σύνδεσμος, κεφαλίδα/υποσέλιδο, αριθμός σελίδας, σύμβολα, ημερομηνία.
- **Σχεδίαση:** σετ στυλ, θέματα εγγράφου (χρώματα & γραμματοσειρές), δικό σας θέμα, ορισμός προεπιλογής.
- **Διάταξη:** περιθώρια, προσανατολισμός, μέγεθος χαρτιού, αλλαγές, εσοχές, διαστήματα.
- **Αναφορές:** πίνακας περιεχομένων με αριθμούς σελίδων, αριθμημένες ενότητες 1 / 1.1 / 1.1.1, λεζάντες.
- **Αναθεώρηση ▸ Ορθογραφία & Γραμματική (F7):** πλαϊνό πάνελ με κάρτες ανά λάθος (ορθογραφία, γραμματική,
  στίξη, ύφος), προτάσεις με ένα κλικ, «Διόρθωση όλων των απλών» σε ένα βήμα αναίρεσης, ↑↓/↵/⌫ από το πληκτρολόγιο,
  προτάσεις και με κλικ πάνω στην υπογραμμισμένη λέξη. Λειτουργεί **offline** σε όλες τις πλατφόρμες: ελληνικό λεξικό
  LibreOffice el_GR (828.000 κλιτοί τύποι, MPL/GPL/LGPL), αγγλικό Hunspell (nspell), προσωπικό λεξικό, και ελληνικοί
  κανόνες (τελικό -ν, «;», « », τόνος μονοσύλλαβων, «ό,τι», «καθένας», πλεονασμοί, κεφαλαία, κενά, έκθλιψη).
  Προαιρετικά (απενεργοποιημένο από προεπιλογή) βαθύτερος έλεγχος γραμματικής μέσω LanguageTool — στέλνει κείμενο online.
- **Εικόνα / Πίνακας / Σχήμα:** καρτέλες που εμφανίζονται με την επιλογή.
- **Αρχείο:** πρότυπα, άνοιγμα & πρόσφατα, αποθήκευση ως DOCX/ODT/Grafi/PDF/HTML/Markdown/TXT, εκτύπωση,
  εκπαίδευση, εμφάνιση (σύστημα / ανοιχτόχρωμο / σκουρόχρωμο) και γλώσσα.
- Χάρακας, ζουμ (και Ctrl/⌘ + τροχός), διάταξη εκτύπωσης/web, σημάδια μορφοποίησης, αναζήτηση εντολών
  (Alt+Q), συντομεύσεις τύπου Word, επαναφορά μη αποθηκευμένου εγγράφου μετά από κλείσιμο/κρασάρισμα,
  επιβεβαίωση κλεισίματος.

## Μορφές αρχείων

| Μορφή | Άνοιγμα | Αποθήκευση | Σημειώσεις |
|---|---|---|---|
| DOCX | ✔ | ✔ | Στυλ, λίστες, πίνακες, εικόνες, κεφαλίδες με αριθμούς σελίδας, ΠΠ, αρίθμηση ενοτήτων, θέμα |
| ODT | ✔ | ✔ | Ίδια κάλυψη· outline numbering του LibreOffice |
| PDF | – | ✔ | Tagged PDF με σελιδοδείκτες από τις επικεφαλίδες |
| .grafi | ✔ | ✔ | Χωρίς απώλειες |
| HTML / MD / TXT | ✔ | ✔ | Με απώλειες μορφοποίησης |

Δείγματα για δοκιμές σε Word / LibreOffice υπάρχουν στο `samples/`.

## Έλεγχοι

- `npm run typecheck`
- Σελιδοποίηση (dev server, κονσόλα): `await __load(60, {tables:true, lists:true, breaks:true, images:true}); __verify()`
  — επιστρέφει γραμμές εκτός σελίδας, ορφανές επικεφαλίδες και σελίδες.
- Electron end-to-end (γέφυρα, αποθήκευση/άνοιγμα DOCX, PDF, τίτλος, πρόσφατα, όρια IPC):
  `GRAFI_SELFTEST=/tmp/out VITE_DEV_SERVER_URL=http://localhost:5199/ npx electron . --user-data-dir=/tmp/grafi-st`
  με τον dev server ανοιχτό· το αποτέλεσμα γράφεται στο `/tmp/out/selftest.json`.
- iOS / Android: build με `VITE_GRAFI_SELFTEST=1` και αρχείο `grafi-selftest` στα Documents της εφαρμογής.

## Mobile builds

```bash
npx vite build && npx cap sync android
cd android && JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" ./gradlew assembleDebug
```

Το APK βγαίνει στο `android/app/build/outputs/apk/debug/app-debug.apk`. Για iOS: `npx cap sync ios` και
άνοιγμα του `ios/App/App.xcodeproj` στο Xcode.

## Γνωστοί περιορισμοί

- Κεφαλίδες/υποσέλιδα είναι μία γραμμή κειμένου με πεδία (`{page}`, `{pages}`, `{date}`, `{title}`).
- Πολλαπλές ενότητες με διαφορετική διαμόρφωση σελίδας, στήλες, υποσημειώσεις, παρακολούθηση αλλαγών,
  σχόλια, εξισώσεις και SmartArt δεν υποστηρίζονται (οι εξισώσεις εισάγονται ως κείμενο).
- Πίνακες ψηλότεροι από μία σελίδα δεν σπάνε ανά γραμμή στην οθόνη (στην εκτύπωση σπάνε κανονικά).
- Σχήμα/περικοπή/σκιά εικόνας αποθηκεύονται ως PNG στο DOCX/ODT· στο .grafi μένουν επεξεργάσιμα.
- Στο Safari (iPhone/iPad) η «Εκτύπωση → PDF» σμικρύνει τη σελίδα· για ακριβές PDF χρησιμοποιήστε την
  εφαρμογή iOS ή Chrome/Edge.
- Για διανομή χρειάζεται υπογραφή κώδικα (Apple Developer ID / Windows code signing).
