# Grafi

Επεξεργαστής κειμένου για **macOS, Windows και Linux** (κατηγορίας Microsoft Word / LibreOffice Writer).
Ανοίγει και αποθηκεύει **DOCX** και **ODT**, εξάγει **PDF**, εκτυπώνει, και η σελιδοποίηση στην οθόνη είναι
ίδια με αυτή που βγαίνει στο χαρτί ή στο PDF.

```bash
npm install
npm run dev          # εφαρμογή Electron με hot reload
npm run dist:mac     # .dmg / .zip   (arm64 + x64)
npm run dist:win     # installer NSIS + portable
npm run dist:linux   # AppImage, .deb, .rpm
```

## 1. Έρευνα: ποια γλώσσα / τεχνολογία

| Επιλογή | Υπέρ | Κατά | Απόφαση |
|---|---|---|---|
| **C++ / Qt** (όπως LibreOffice, Calligra) | Μέγιστη απόδοση, native | Χρόνια δουλειάς για μηχανή διάταξης κειμένου, BiDi, shaping, IME, ορθογραφία | Όχι |
| **Rust + Tauri** | Μικρό binary | Το WebView διαφέρει ανά OS (WebKit στο macOS/Linux, Chromium στα Windows): άλλη διάταξη κειμένου, άλλη εκτύπωση ⇒ **η σελιδοποίηση δεν θα ήταν ίδια παντού** | Όχι |
| **Flutter** | Ένα codebase | Αδύναμη επεξεργασία πλούσιου κειμένου, IME, εκτύπωση | Όχι |
| **.NET MAUI / Avalonia** | C# | Δεν υπάρχει ώριμος rich-text editor με σελιδοποίηση | Όχι |
| **TypeScript + Electron** | **Ίδιος μηχανισμός διάταξης (Chromium) σε όλα τα OS**, ώριμη εκτύπωση και `printToPDF`, ενσωματωμένος ορθογράφος, ProseMirror για το μοντέλο εγγράφου | Μεγαλύτερο μέγεθος εφαρμογής (~350 MB) | **Ναι** |

Το καθοριστικό κριτήριο ήταν η **πιστότητα**: ένας επεξεργαστής κειμένου πρέπει να σπάει γραμμές και σελίδες
με τον ίδιο τρόπο σε κάθε υπολογιστή. Με Electron ο ίδιος Chromium κάνει διάταξη, εκτύπωση και PDF σε macOS,
Windows και Linux. Επιπλέον ενσωματώνονται γραμματοσειρές **metric-compatible**: Carlito (≅ Calibri) και
Arimo (≅ Arial), ώστε το κείμενο να αναδιπλώνεται ίδια ακόμα και σε υπολογιστή χωρίς Office.

**Στοίβα:** TypeScript · React 19 · TipTap 3 / ProseMirror · Electron 44 · Vite 8 · `docx` (γραφή DOCX) ·
δικός μας reader WordprocessingML · δικός μας reader/writer ODF · JSZip.

```

```

### Σελιδοποίηση (Print Layout)
Το έγγραφο επεξεργάζεται ως μία στήλη με το πλάτος κειμένου της σελίδας. Μετά από κάθε αλλαγή μετριέται η
«φυσική» θέση κάθε γραμμής και ένας αλγόριθμος τοποθετεί αόρατα spacers (decorations, όχι περιεχόμενο) ώστε:
- καμία γραμμή να μη διασχίζει το κάτω περιθώριο — οι παράγραφοι σπάνε ανάμεσα σε γραμμές·
- έλεγχος ορφανών/χήρων γραμμών (ποτέ μόνη η πρώτη ή η τελευταία γραμμή)·
- οι επικεφαλίδες μένουν με την επόμενη παράγραφο·
- πίνακες/εικόνες μετακινούνται ολόκληρα· «τετράγωνες» εικόνες σπάνε μόνο κάτω από την εικόνα·
- στην εκτύπωση κάθε spacer γίνεται αναγκαστική αλλαγή σελίδας ⇒ **PDF = οθόνη**.

**Επαλήθευση (αυτοματοποιημένη):** 6 μεγέθη χαρτιού (A4, A4 οριζόντιο, Letter, A5, A3, Legal), ~4.400 γραμμές με
πίνακες, λίστες, εικόνες και αλλαγές σελίδας: 0 γραμμές εκτός σελίδας, 0 ορφανές επικεφαλίδες. Σε 4 σενάρια
PDF μέσω Electron: ίδιος αριθμός σελίδων, και κάθε σελίδα (19/19) ξεκινά με το ίδιο κείμενο όπως στην οθόνη.
Στο dev: `__load(60, {tables:true, lists:true, breaks:true, images:true}); __verify()` στην κονσόλα.
Έλεγχος end-to-end της εφαρμογής: `GRAFI_SELFTEST=/tmp/out VITE_DEV_SERVER_URL=http://localhost:5199/ npx electron . --user-data-dir=/tmp/grafi-st`
(το `--user-data-dir` επιτρέπει να τρέξει ενώ το Grafi είναι ήδη ανοιχτό).

**Περιθώρια PDF = Word.** Μετρημένα στο PDF (A4, 25,4 mm): desktop 25,4 mm αριστερά/δεξιά, iOS 25,5 mm, με ίδιο
μέγεθος γραμμάτων. Στο iOS ο print formatter του WebKit στήνει τη σελίδα σε δικό του πλάτος και τη σμικρύνει
(~86 %, δηλ. ~37 mm κενό δεξιά/αριστερά)· γι' αυτό το Grafi εκεί «φωτογραφίζει» διανυσματικά κάθε σελίδα της οθόνης
(`WKWebView.createPDF`, `platform.ts → withPageRects`) και την τοποθετεί ακριβώς στο χαρτί
(`AppDelegate.swift → capturePages`). Το Android χρησιμοποιεί Chromium, όπως το desktop.

## 3. Λειτουργίες

- **Κεντρική:** επικόλληση/αποκοπή/αντιγραφή, πινέλο μορφοποίησης, γραμματοσειρές Calibri/Arial/Tahoma, μέγεθος,
  μεγέθυνση/σμίκρυνση, πεζά-κεφαλαία, απαλοιφή μορφής, Έ/Π/Υ/Δ, δείκτης/εκθέτης, επισήμανση, χρώμα,
  κουκκίδες & αρίθμηση (βιβλιοθήκες), λίστα ελέγχου, εσοχές, στοίχιση, διάστιχο, σκίαση παραγράφου,
  συλλογή στυλ, εύρεση/αντικατάσταση (με/χωρίς τόνους, ολόκληρες λέξεις, regex).
- **Εισαγωγή:** αλλαγή/κενή σελίδα, πίνακας (πλέγμα ή διάλογος), εικόνες (αρχείο, URL, επικόλληση, σύρσιμο),
  γραμμή, παράθεση, κώδικας, σύνδεσμος, κεφαλίδα/υποσέλιδο, αριθμός σελίδας (πρότυπα), σύμβολα, ημερομηνία.
- **Σχεδίαση:** 6 σετ στυλ (Teal, Κλασικό Office, Ασπρόμαυρο, Μοντέρνο, Επίσημο, Φρέσκο) — αλλάζουν μαζί
  Τίτλο, Υπότιτλο και Επικεφαλίδες 1–6.
- **Διάταξη:** περιθώρια (προκαθορισμένα/προσαρμοσμένα), προσανατολισμός, μέγεθος χαρτιού, αλλαγές, εσοχές, διαστήματα.
- **Αναφορές:** αυτόματος Πίνακας Περιεχομένων με αριθμούς σελίδων, **αριθμημένες ενότητες 1 / 1.1 / 1.1.1**,
  λεζάντες «Εικόνα N:» / «Πίνακας N:» με αυτόματη αρίθμηση.
- **Εικόνα (όταν επιλέγεται):** μόνο 2 τρόποι αναδίπλωσης — **Πάνω & κάτω** (δική της ζώνη, σύρσιμο οπουδήποτε,
  αριστερά/κέντρο/δεξιά) και **Τετράγωνη** (μέσα στο κείμενο, αριστερά/δεξιά)· περικοπή σε 8 σχήματα, περικοπή σε
  αναλογία (1:1, 4:3, 3:4, 16:9, 3:2) με μετατόπιση κάδρου (διπλό κλικ), 4 σκιές, μέγεθος, εναλλακτικό κείμενο.
- **Πίνακας (όταν επιλέγεται):** γραμμές/στήλες, διαγραφή, συγχώνευση/διαίρεση, γραμμή κεφαλίδας, σκίαση, κάθετη στοίχιση.
- **Αρχείο:** πρότυπα (Κενό, Επιστολή, Αναφορά, Βιογραφικό, Πρακτικά), άνοιγμα & πρόσφατα, αποθήκευση ως
  DOCX/ODT/Grafi/PDF/HTML/Markdown/TXT, εκτύπωση, ιδιότητες.
- Χάρακας με σύρσιμο περιθωρίων και εσοχών, ζουμ (και Ctrl/⌘+τροχός), διάταξη εκτύπωσης/Web, σημάδια μορφοποίησης,
  ορθογραφία (δεξί κλικ για προτάσεις), συντομεύσεις τύπου Word, αυτόματο αντίγραφο ασφαλείας, επιβεβαίωση κλεισίματος.

## 4. Μορφές αρχείων

| Μορφή | Άνοιγμα | Αποθήκευση | Σημειώσεις |
|---|---|---|---|
| DOCX | ✔ | ✔ | Στυλ, λίστες, πίνακες, εικόνες (inline/αιωρούμενες), κεφαλίδες με αριθμούς σελίδας, ΠΠ, αρίθμηση ενοτήτων |
| ODT | ✔ | ✔ | Ίδια κάλυψη· outline numbering του LibreOffice |
| PDF | – | ✔ | Tagged PDF με σελιδοδείκτες από τις επικεφαλίδες |
| .grafi | ✔ | ✔ | Χωρίς απώλειες (π.χ. σχήματα εικόνων παραμένουν επεξεργάσιμα) |
| HTML / MD / TXT | ✔ | ✔ | Με απώλειες μορφοποίησης, όπως αναμένεται |

Ο round-trip DOCX → Grafi → DOCX και ODT → Grafi → ODT ελέγχθηκε δομικά (ταυτόσημη δομή).
Δείγματα στο `samples/` για άνοιγμα σε Word / LibreOffice.

## 5. Γνωστές διαφορές από το Word (ειλικρινά)

- Κεφαλίδες/υποσέλιδα είναι μία γραμμή κειμένου με πεδία (`{page}`, `{pages}`, `{date}`, `{title}`), όχι πλήρες έγγραφο.
- Πολλές ενότητες με διαφορετική διαμόρφωση σελίδας, στήλες, υποσημειώσεις, παρακολούθηση αλλαγών, σχόλια,
  εξισώσεις και σχήματα/SmartArt δεν υποστηρίζονται ακόμη (οι εξισώσεις εισάγονται ως κείμενο).
- Πίνακες ψηλότεροι από μία σελίδα δεν σπάνε ανά γραμμή στην οθόνη (στην εκτύπωση σπάνε κανονικά).
- Σχήμα/περικοπή/σκιά εικόνας «ψήνονται» σε PNG στο DOCX/ODT, ώστε να φαίνονται ίδια παντού· στο Word η εικόνα
  δεν είναι πια επεξεργάσιμη ως σχήμα (στο .grafi παραμένει).
- Web app σε Safari του iPhone/iPad: η «Εκτύπωση → PDF» του Safari σμικρύνει τη σελίδα (περιορισμός του WebKit)·
  για ακριβές PDF σε iOS χρησιμοποιήστε την εφαρμογή Grafi (native) ή Chrome/Edge σε υπολογιστή.
- Η εφαρμογή δεν είναι υπογεγραμμένη· για διανομή χρειάζεται πιστοποιητικό Apple Developer ID / Windows code signing.
